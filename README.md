# KiCAD_Workshop_TBP
This is a workshop I designed to teach PCB design skills on KiCAD to engineering students (Beginner-level).

KiCAD_Workshop_TBP.pdf Contains all necessary information for facilitating the session. 

The workshop includes a conceptual introduction to Symbols, Schematics, Footprints, and PCB Layout Design and exporting.
Participants are walked through creating a project from scratch, using the KiCAD digital library, placing and arranging symbols in a schematic, assigning footprints to symbols, and translating the schematic into a practical and personalized board design.

Importing symbol, footprint, and step files to build a custom parts library is outside of this workshop's scope. Thus, it relies only on parts found within KiCAD's default library.

At the end of the workshop, participants should be able to navigate KiCAD confidently and design simple PCBs on their own.
